3. 打开 `http://localhost:4173`。本机演示数据保存在当前浏览器；注册或登录后，云端功能连接上面的 `kangban` 项目。

## 后续 CLI 操作

如需继续由 Supabase CLI 管理迁移，先在本机执行 `npx supabase@latest login`，并把项目关联到本地：

```sh
npx supabase@latest link --project-ref vlxdgdrjbomdarrkrctc
npx supabase@latest migration list
npx supabase@latest migration repair --status applied 20261105160000 --project-ref vlxdgdrjbomdarrkrctc
npx supabase@latest migration list
npx supabase@latest db push
```

`migration repair` 只登记已经由 SQL Editor 成功执行的第四份迁移，不会再跑一次 SQL。确认 `migration list` 中四份迁移均已应用后，后续才能常规执行 `db push`。不要重新运行第四份 SQL。
