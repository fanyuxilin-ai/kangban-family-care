## 本机运行

1. `.env` 已配置好，可按需运行 `node scripts/generate-supabase-config.mjs` 刷新被忽略的浏览器配置文件。
2. 在仓库根目录运行 `python3 -m http.server 4173`。
3. 打开 `http://localhost:4173`。本机演示数据保存在当前浏览器；注册或登录后，云端功能连接上面的 `kangban` 项目。

## 后续 CLI 操作

如需继续由 Supabase CLI 管理迁移，先在本机执行 `npx supabase@latest login`，然后：

```sh
npx supabase@latest link --project-ref vlxdgdrjbomdarrkrctc
npx supabase@latest migration list
npx supabase@latest db push
```

迁移历史已为三份现有文件登记，正常情况下 `db push` 应报告无待执行迁移。若 CLI 发现历史不一致，应先检查 `migration list`；不要重复直接执行现有 SQL。
