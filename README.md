# 康伴 · 家庭就医助手

**项目简介：**帮助家庭把分散的就医资料整理成一张由患者确认、可按需授权的就医信息卡，让重要信息在就诊时更容易交接。

康伴是一个手机优先的家庭就医协同原型。本项目没有接入真实患者、医院或云端数据；内置病例均为虚构样例。

## 当前功能

- **家庭端五 Tab 分区：**家庭端按功能域分为「首页 / 健康档案 / 医疗资料 / 陪诊 / 我的」五个 Tab——首页只放状态与入口，健康档案承载档案概览、日常记录与健康趋势，医疗资料承载就医信息卡、就诊准备、分享码、资料库与保险报销入口，陪诊承载陪诊服务全流程，我的承载家庭成员、AI 助手与设备管理入口。
- **模拟账号与四人健康档案：**内置父母 + 子女四位家庭成员模拟账号，可在顶栏切换视角；健康档案 Tab 中每位成员的档案（慢病/过敏/用药/手术史）均可展开折叠、编辑保存。
- **体检看板与异常指标跟踪：**每位成员可查看体检看板——统计卡（最近体重/体重变化/记录次数/异常待随访）、多指标趋势图、化验报告区（按天/按检查类别/全部/只看异常筛选，日期分组可折叠）与历史时间线（可编辑/删除）；支持"导入体检单"模拟 OCR 识别一份 17 项 / 6 个检查类别的完整报告（血常规、血脂四项、肝肾功能等），核对入库后异常指标自动进入跟踪并生成一般预警；**报告上基础表之外的新指标会连同参考范围自动登记进系统**（指标体系随报告扩展，无需改代码）。
- **家庭就医准备：**管理就诊清单，并记录诊前自我描述，包括症状变化、饮食、睡眠、排便和活动等情况；支持文字、照片和语音相关入口。
- **资料采集与归档：**添加检查资料和用药信息；图片可在本机通过 Tesseract.js 进行中英文文字识别，识别结果可人工编辑核对后保存。
- **服药提醒：**从识别文字生成药名、剂量、频次和医嘱明确写出的时间草稿；由家人逐项核对后保存计划并记录已服。医嘱未写清的内容不会由系统推断。
- **家庭档案与就医信息卡：**汇总家庭成员信息、检查资料和用药信息，便于就诊前整理和查看。
- **信息授权演示：**展示分享范围、短时二维码样式、访问记录和撤销入口。
- **陪诊流程演示：**家庭端可查看陪诊员介绍、预约、查看进度、互评和再次预约；陪诊员端可编辑介绍、接受预约、标记完成并互评。
- **健康预警（规则版）：**录入或模拟手表同步血压读数后，按固定规则生成红色（紧急）/ 黄色（关注）/ 蓝色（一般）三级预警；按级别完成分级告知（红色电话外呼与强提醒、黄色 App 推送、蓝色进入每日汇总），全过程在预警中心留痕。漏服提醒超时也会触发黄色预警。
- **陪诊履约清单与佐证：**陪诊员接单后按项目清单逐项执行并上传现场佐证照片，全部完成后才能标记服务完成；家庭端可实时查看履约进度与佐证。

## 技术与数据说明

康伴为静态网页应用，可作为 PWA 添加到手机主屏幕。资料、提醒、预约和附件保存在当前设备浏览器本机，不会自动同步到云端或进入 Git 仓库。陪诊角色、预约和授权界面为本机模拟，没有真实账号、跨设备同步、服务人员核验或线上派单。

OCR 在本机浏览器运行。首次使用时需要加载并缓存识别组件，之后可离线识别。清晰印刷体通常更适合自动识别；医生手写中文无法保证准确，识别结果必须人工核对。可信度较低时不会自动填充资料字段或开放用药提醒生成。PDF 目前作为附件保存，字段需手动录入。

语音功能取决于浏览器支持、安全上下文和麦克风权限。浏览器关闭或设备离线时，当前版本不能保证后台定时推送。

第三方组件许可见 `THIRD_PARTY_NOTICES.md`。

## 本地运行

双击 **启动康伴.command** 可启动本机演示，并在终端显示同一 Wi‑Fi 下手机可访问的地址。也可以在项目目录运行：

```bash
python3 -m http.server 4173
```

然后在浏览器打开 `http://localhost:4173`。手机和电脑连接同一 Wi‑Fi 后，可在手机浏览器打开电脑的局域网地址；也可以将页面添加到主屏幕。

## 建议演示流程

打开家庭首页 → 勾选就诊准备项 → 添加虚构资料并确认识别内容 → 查看就医信息卡 → 浏览分享授权界面 → 从家庭端预约陪诊 → 切换陪诊员角色接单并完成 → 返回家庭端评价并再次预约。

可在“整理资料”中选择虚构报告或虚构处方快速体验。演示资料均为虚构内容。

## 隐私与责任边界

- 本原型不用于真实医疗服务，不提供诊断、治疗或用药建议。
- 请勿用真实患者姓名、报告、处方、保单、联系方式或其他个人身份信息进行演示。
- OCR 结果须人工核对；药名、剂量、频次和提醒时间应由患者或家属根据医嘱确认。
- 二维码、访问记录、预约和互评均为界面演示，不代表真实安全授权或服务资质核验。
